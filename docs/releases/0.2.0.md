# elkrs 0.2.0 Release Notes

Date: 2026-06-02

`0.2.0` is an interim clean-room Git dependency release candidate. It captures
the current expanded JSON, diagnostics, parity inventory, and Java-oracle
evidence work without claiming full ELK Layered parity.

## Included

- Workspace crate versions are aligned at `0.2.0`.
- Canonical ELK JSON option import/export is expanded for the current Layered
  subset.
- Additional recognized but unsupported options now produce deterministic
  diagnostics instead of being invisible to consumers.
- Nodes marked with `org.eclipse.elk.noLayout` preserve their input
  coordinates during layout.
- `org.eclipse.elk.spacing.nodeSelfLoop` controls node self-loop route
  clearance.
- `org.eclipse.elk.spacing.portPort` positions default-geometry same-side
  ports using graph and node layout options.
- The parity matrix is backed by pinned Java ELK v0.11.0 metadata inventory.
- The optional Java oracle suite includes additional deterministic behavior
  fixtures.
- Local release verification uses the workspace formatting, lint, test, docs,
  and parity-inventory gates.

## Not Included

- Full ELK Layered v0.11.0 parity.
- Full option semantics for every metadata row.
- crates.io distribution.
- CLI support.
- Dediren adapter support.
- Pixel-perfect Java coordinate parity.

## Required Local Gate

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
cargo doc --workspace --locked --no-deps
python3 tools/parity/layered_inventory.py --metadata docs/parity/generated/elk-layered-v0.11.0-metadata.json --matrix docs/parity/elk-layered-v0.11.0.md
git diff --check
```
