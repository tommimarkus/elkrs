# elkrs 1.0.0 Release Notes

`1.0.0` is the first stable Git dependency release candidate for the clean-room
Rust port of ELK Layered v0.11.0 behavior, excluding external plugins and rows
with documented 1.0.0 compatibility exclusions.

Distribution remains scoped to GitHub Releases and pinned Git dependencies.
This release is not published to crates.io.

## Supported Surface

- Workspace crate versions are aligned at `1.0.0`.
- `elkrs-core` provides graph, geometry, option, diagnostic, and layout result
  types for the supported Layered surface.
- `elkrs-layered` provides the library-first `LayeredLayout` implementation for
  the supported clean-room Layered contract.
- `elkrs-json` imports, exports, and validates the supported ELK-style JSON
  graph, node, edge, port, label, edge-section, and option contract.
- Unknown JSON fields and represented-but-out-of-scope known options are
  accepted where documented and are not re-emitted.
- Java-backed parity evidence covers directed graphs, multi-edges, ordinary
  self-loops, ports as endpoints, compound nodes, hierarchy-crossing edges,
  direction, spacing, node labels as size inputs, node size constraints, layer
  assignment defaults, orthogonal routing, component spacing, and adjacent-layer
  crossing minimization.

## Boundaries

This release does not claim:

- External plugin behavior.
- crates.io distribution.
- CLI or Dediren adapter support.
- ELK algorithms outside Layered.
- Matrix rows documented as 1.0.0 compatibility exclusions.
- Pixel-perfect Java coordinate parity.

The authoritative compatibility record is
`docs/parity/elk-layered-v0.11.0.md`.

## Verification

The release gate is:

```bash
export PATH="$PWD/.cache/cargo-install/bin:$PATH"
cargo audit
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
cargo doc --workspace --locked --no-deps
tools/java-elk-json-runner/bin/build
ELKRS_JAVA_ELK_COMMAND="$PWD/tools/java-elk-json-runner/bin/java-elk-json" cargo test -p elkrs-layered --test java_parity --locked -- --ignored
```
