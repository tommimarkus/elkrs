# Security Policy

## Supported Versions

This project is discontinued. No versions, branches, tags, or release lines are
currently supported with security fixes.

## Reporting a Vulnerability

If you need to report a vulnerability in historical code, use GitHub Security
Advisories for `tommimarkus/elkrs`. Reports may not receive a remediation
commit or release because the project is no longer maintained.

Do not file public issues for exploitable vulnerabilities until a fix is available.

Historical response target before discontinuation:

- Initial acknowledgement within 7 calendar days.
- Status update or remediation plan within 30 calendar days.
- Critical reachable supply-chain or parser vulnerabilities prioritized ahead of feature work.

## Security Targets

The former `1.0.x` release target was:

- SCVS Level 1 for dependency, provenance, and release-evidence practices that apply to a Rust library crate.
- SLSA Build Level 1 evidence for GitHub-built release artifacts.

These targets do not claim external plugin behavior, runtime deployment
controls, production service monitoring, or ongoing maintenance.
