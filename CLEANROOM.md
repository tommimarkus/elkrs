# Clean-Room Policy

Allowed inputs:

- Public ELK docs and reference pages
- Public API behavior and option metadata
- Hand-authored ELK-style examples and fixtures
- Black-box Java ELK v0.11.0 executable output
- Downstream consumer fixtures

Disallowed inputs:

- Eclipse ELK algorithm source
- Line-by-line Java processor translations
- Copied Java comments or internal implementation text
